# مجلد مرجع — قاعدة معرفة البوت

كل ملف تضعـه هنا **يتعلم منه البوت تلقائياً** ويجيب منه حصراً.

## الصيغ المدعومة

| الصيغة | الاستخراج |
|---|---|
| `.pdf` | نص كل صفحة (PDF نصي — الصور الممسوحة تُقرأ كصور) |
| `.docx` | الفقرات + الجداول |
| `.txt` `.md` `.csv` | نص مباشر |
| `.jpg` `.png` `.webp` | قراءة بصرية (OCR) عبر Gemini |

> `.doc` القديم غير مدعوم — افتحه في Word واحفظه بصيغة `.docx`.

## ماذا تضع هنا؟

- النظام الأساسي للخدمات الاجتماعية
- القوانين الداخلية والمنشورات الوزارية
- مواعيد العمل والعطل
- الإعلانات الرسمية
- قائمة الأسئلة الشائعة (يفضّل ملف `faq.txt` بصيغة: سؤال ثم سطر يبدأ بـ `ج:`)
- صور الإعلانات المطبوعة

## كيف يعمل؟

1. ضع الملفات هنا ثم شغّل: `python ingest.py`
2. البوت يفهرس كل شيء ويجيب **فقط** من هذه الوثائق.
3. إذا لم يجد الإجابة، يعتذر بأدب ويسجّل الاستفسار للتدخل البشري.
4. أضفت ملفاً جديداً؟ أعد تشغيل `python ingest.py` أو أعد نشر الخدمة.

## نصائح لجودة أعلى

- أضف عنواناً واضحاً في بداية كل ملف (مثلاً: «دليل الخدمات الاجتماعية — 2026»).
- اكتب الأرقام والمواعيد صراحة (وليس «قريباً»).
- الصور يجب أن تكون واضحة وبإضاءة جيدة لنجاح القراءة.
- لا تضع وثائق تحتوي بيانات شخصية حساسة لعمال دون إذن.
